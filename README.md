# autopost — страница для телефона

Статическая страница: отправляет контент-план в приватный бакет Backblaze B2 и показывает ответы
и календарь с Mac, на котором работает autopost.

- В файлах нет ни адреса бакета, ни ключей. Адрес и бакет приходят в ссылке (после `#`) или вводятся
  в форме; ключ телефона вводится на странице и хранится только в этом браузере («Забыть ключ» стирает его).
- Файлы публикует команда `autopost-inbox publish-page` из основного проекта — правьте их там.
