# autopost — пульт для телефона

Статическая страница (ES-модули без сборки): отправляет контент-план в приватный бакет Backblaze B2,
показывает календарь, аккаунты и журнал Mac, на котором работает autopost, и передаёт ему команды
(пауза, правка поста, лимиты аккаунта). Запросы к бакету подписываются прямо в браузере.

- В файлах нет ни адреса бакета, ни ключей. Адрес и бакет приходят в ссылке (после `#`) или вводятся
  в форме; ключ вводится на странице и хранится только в этом браузере («Забыть ключ» стирает его).
- `vendor/xlsx-0.20.3.mjs` — SheetJS Community Edition 0.20.3 (Apache-2.0, `vendor/LICENSE-SheetJS.txt`),
  нужен только чтобы узнать рубрики в таблице.
- Файлы публикует команда `autopost-inbox publish-page` из основного проекта — правьте их там.
